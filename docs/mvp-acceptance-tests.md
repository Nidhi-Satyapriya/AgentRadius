# MVP acceptance tests

Each MVP criterion is mapped to the automated tests that check it. Run all of them with `npm test`, or the full gate with `npm run check`.

Status key:

- ✅ covered by the listed tests.
- ◐ partly covered (the gap is stated).
- ◻ not yet implemented.
- n/a does not apply to a single-user local tool (reason given).

The criteria come from the starter list (`docs/archive/starter/docs/mvp-acceptance-tests.md`) and the project brief. The criteria are kept as written; the starter file itself is not modified.
