# Feature matrix

How to read this table:

- **Evidence** uses the labels from [`source-register.md`](./source-register.md).
- **Priority:**
  - P0: in the current MVP.
  - P1: next phase.
  - P2: later.
  - Avoid: an explicit anti-requirement.
- **Status** at the end of each requirement:
  - ✅ implemented and tested.
  - ◻ planned.
